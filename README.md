# Territory Scramble — English / 日本語 player guide

An illustrated manual preview covering enclosure rules and Machine Gun, Armor and Heal. Use English / 日本語 in the header to switch languages. English: `index.html`. Japanese: `ja.html`. Chapter anchors are preserved when JavaScript is enabled; plain language links also work without JavaScript.
