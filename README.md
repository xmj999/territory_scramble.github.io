# Territory Scramble — English player guide

An illustrated manual preview covering enclosure rules and Machine Gun, Armor and Heal.

## GitHub Pages

The repository is private; the published website is intended to be public.
Publish from **main / (root)** under **Settings → Pages → Deploy from a branch**.
Private-repository Pages requires an eligible GitHub plan.

Expected project URL: https://xmj999.github.io/territory_scramble.github.io/

No build step is required. `index.html`, `styles.css`, `manual.js` and `assets/` make up the website. Relative asset paths support the project URL. `.nojekyll` serves these files directly.

## Content and images

Images come from a running local game, staged for explanation with the HUD hidden and camera adjusted. The enclosure pair uses the actual game capture logic. Item images show actual pickup prefabs.

This is a preview, not the complete manual. Menu, lobby, base capture, the remaining five items and other languages are not yet covered.

Source snapshot: game repository commit `f1be014`, `website/manual/dist/`. Update the manual in the game repository, then copy the HTML, CSS, JavaScript and PNG images here. Do not upload the game source, raw models, credentials or hosting configuration for other services.
